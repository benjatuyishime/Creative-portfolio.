# Creative Portfolio Starter

A responsive, minimalist graphic design portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — layout, typography and responsive styles
- `script.js` — mobile navigation and current year

## Preview locally
Open `index.html` in your browser.

## Personalize before publishing
1. Replace `Your Name` and `YN` with your name/initials.
2. Update the intro, about text, services and contact email.
3. Replace the three CSS-generated sample project visuals with your real project images.
4. Update Behance, Instagram and LinkedIn links.
5. Update the page title and description in `index.html`.

## Publish
Push these files to a GitHub repository, import that repository into Vercel, and add your custom domain in Vercel's project settings.
